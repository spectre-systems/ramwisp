# Contributing

Issues and pull requests are welcome.

- Every pull request is covered by the [Contributor License Agreement](CLA.md). Opening a PR means you agree to it.
- `mcp/` and `enclave/` are Apache-2.0; the rest of the repo is under the [ramwisp Sustainable Use License](LICENSE-SUL.md).
- Security issues: please do not open a public issue. Email Spectre Systems instead.
- Never commit secrets. `server/.env` and `.env.*` are ignored; use `server/.env.example` as a template.
